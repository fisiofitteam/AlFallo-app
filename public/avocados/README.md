# Aguacates 🥑

Arrastra aquí las imágenes de los aguacates mascota (PNG con fondo transparente
recomendado). Cuando una imagen existe con el nombre correcto, la pantalla de
inicio del atleta la usa automáticamente en lugar del icono de placeholder.

Nombres esperados (uno por tarjeta):

| Archivo            | Tarjeta       |
|--------------------|---------------|
| `plan.png`         | Mi plan       |
| `recetas.png`      | Recetas       |
| `compra.png`       | Tu compra     |
| `checkin.png`      | Check-in      |
| `registro.png`     | Registro      |
| `progreso.png`     | Mi progreso   |
| `training.png`     | Entreno       |
| `nutri.png`        | Tu nutri      |

También se aceptan extensiones `.webp` y `.jpg`.

Recomendado: ~512×512 px, fondo transparente, mascota centrada.
